# TryTech

**Desenvolvimento de software e open source.**

Somos uma empresa de desenvolvimento de software focada em construir produtos digitais de alta qualidade e contribuir para o ecossistema open source. Do conceito ao produto, com foco em arquitetura sólida, código limpo e soluções que escalam.

## O que fazemos

- **Desenvolvimento de software** — Aplicações web, APIs e sistemas sob medida com Ruby on Rails, TypeScript, PostgreSQL e mais
- **Performance e escalabilidade** — Arquitetura e otimização para que seu produto cresça sem perder velocidade
- **Consultoria técnica** — Code review, mentoria e decisões técnicas que fazem diferença no longo prazo
- **Open source** — Contribuições ativas para a comunidade. Código aberto está no nosso DNA
